# Stas Ganiev

In 1C since 2001. I build AI pipelines for development and teach others how.

Senior 1C Developer at SOFTSWISS, author of two courses for developers. Based in Novi Sad, Serbia.

## Open source

- **[OnesTemplates](https://github.com/stasganiev/OnesTemplates)**: code templates for 1C Designer. Type a few letters and get a ready block of code.
- **[1c_vibecoding_agents](https://github.com/stasganiev/1c_vibecoding_agents)**: Claude Code commands and subagents that take a 1C task from requirements to reviewed code.
- **[ut11_aiarsenal_course](https://github.com/stasganiev/ut11_aiarsenal_course)**: demo configuration for the AI Arsenal course.
